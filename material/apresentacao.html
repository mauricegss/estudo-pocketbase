1. Identificação da Tecnologia

Visão Geral e Origem

🌐 Dados Oficiais

Nome: PocketBase

Site Oficial: https://pocketbase.io

Ano de Criação: 2022 (Criado por Gani Georgiev)

Licença: MIT (100% Livre e Open Source)

🎯 Proposta de Valor

Eliminar a complexidade de configurar bancos de dados externos, ORMs, serviços de autenticação e servidores HTTP separados para projetos web, mobile e protótipos rápidos.

Oferece a experiência de um Firebase/Supabase totalmente auto-hospedável (self-hosted), sem custos ocultos e sem dependência de serviços em nuvem proprietários.

2. Área da Tecnologia

Posicionamento no Ecossistema

⚙️ Backend & BaaS

Atua como Backend-as-a-Service (BaaS). Gera automaticamente rotas REST para qualquer coleção modelada no banco, com regras de acesso e validações.

🗄️ Database Embarcado

Utiliza SQLite nativo com suporte ao modo WAL (Write-Ahead Logging), proporcionando leituras concorrentes ultrarrápidas sem overhead de rede.

🔐 Segurança & Auth

Serviço de autenticação completo integrado: login por Email/Senha, OAuth2 (Google, GitHub, Discord, etc.) e gerenciamento de tokens JWT.

3. Recursos Técnicos

Funcionalidades Principais

✨ Principais Capacidades

  • CRUD Automático: List, View, Create, Update e Delete instantâneos.
  • Realtime Subscriptions: Eventos em tempo real via Server-Sent Events (SSE).
  • Admin Dashboard Integrado: Interface web embutida para modelar dados e gerenciar usuários.
  • File Storage: Upload de arquivos local ou integrado a buckets S3 / R2 / MinIO.

🔌 Extensibilidade & Regras

  • API Rules Declarativas: Controle de acesso a nível de registro via filtros intuitivos.
  • JavaScript Hooks: Criação de lógica de negócio e triggers personalizados via JS.
  • Extensão em Go: Pode ser importado como biblioteca Go em aplicações complexas.
  • Backup Simples: O banco inteiro é um único arquivo (pb_data/data.db).
4. Deploy & Plataformas

Deploy e Drivers / SDKs

🚀 Onde Fazer Deploy

Como é um único executável estático, pode ser hospedado em praticamente qualquer lugar:

  • Servidores VPS: Hetzner, DigitalOcean, Linode, AWS EC2 ($3-$5/mês).
  • PaaS & Containers: Fly.io, Railway, Render, Coolify, CapRover.
  • Edge / IoT / On-Premise: Raspberry Pi, servidores locais offline ou redes internas.

📦 SDKs e Clientes Oficiais

Bibliotecas prontas para integração de frontends e apps:

  • JavaScript / TypeScript SDK: Web, Node.js, React, Vue, Svelte, Angular.
  • Dart / Flutter SDK: Aplicativos Mobile iOS & Android.
  • Drivers da Comunidade: Python, Go, C# (.NET), Swift, Rust.

6. Estudo de Caso Prático

Migração de Firebase ➔ PocketBase

⚠️ O Problema (Antes)

Startup SaaS enfrentava custos crescentes de leitura/escrita no Firebase ($150+/mês), latência de rede variável e complexidade de regras de segurança no console.

✅ O Resultado (Depois)

Migração para PocketBase rodando em um VPS simples da Hetzner de €4/mês:

  • Economia de >90%: Custo fixo previsível de menos de R$ 30/mês.
  • Latência Sub-Milissegundo: SQLite embarcado no mesmo processo.
  • Total Controle: Backup instantâneo do arquivo de banco de dados.
7. Demonstração Prática

Aplicação ToDo App Local

🛠️ Arquitetura da Demo

Backend: pocketbase.exe serve rodando na porta 8090 com a collection tarefas.

Frontend: Interface web limpa em index.html consumindo o PocketBase JS SDK.

Operações Testadas (CRUD):

  • Create: Inserir nova tarefa.
  • Read: Listar tarefas salvas no SQLite.
  • Update: Alternar status e registrar data de encerramento.
  • Delete: Excluir registros do banco.

💻 Código da Integração (JS SDK)

const pb = new PocketBase('http://127.0.0.1:8090');
// 1. Leitura (Read)
const list = await pb.collection('tarefas').getFullList();
// 2. Criação (Create)
await pb.collection('tarefas').create({ titulo: 'Apresentar PocketBase', concluida: false });
// 3. Atualização (Update)
await pb.collection('tarefas').update(id, { concluida: true });
// 4. Exclusão (Delete)
await pb.collection('tarefas').delete(id);
